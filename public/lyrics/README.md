# 歌词目录

放 `.lrc` 格式的歌词文件，**一首歌一个文件**，文件名 = 歌单里的曲目 id（例如 `ivory-tower.lrc`）。

这里是歌词**唯一**的存放位置，歌词直接放进来即可。

## 怎么用（推荐：`npm run lyrics`）

1. 把歌词文件**直接放进本目录**，文件名用**歌单里的 id 或标题**都行：

   ```
   public/lyrics/ivory-tower.lrc    ← 按 id（推荐，也是最终形态）
   public/lyrics/还是分开.lrc        ← 按标题
   public/lyrics/春娇与志明.txt      ← 纯文本也行（会转成无时间轴歌词）
   ```

   > 注释行（`#` 开头）会被忽略，所以可以像 `.txt` 那样一行一句直接贴；
   > 已经有带时间轴的 LRC 的话，整段贴进来也认（`[00:12.34]这是一句歌词`）。

2. 跑一次：

   ```bash
   npm run lyrics
   ```

脚本会做三件事：

- 补上缺失的 `[ti:]` / `[ar:]` 元信息
- 统一成 `public/lyrics/<id>.lrc` —— 按标题命名或 `.txt` 的会**就地改名**并删掉原文件，
  不会在目录里留下两份
- 在 `src/lib/music.ts` 对应条目里插一行 `lyrics: lyricSrc("<id>.lrc"),`

已经登记过的只更新文件内容，不会重复写；文件里没有正文（只剩注释 / 空）会被跳过，
不会生成空歌词文件；文件名对不上的也会单独列出来。跑完会打印「歌词 ⇄ 歌曲」对照表，
一眼看出哪首还缺词。

## 手工加（也可以）

1. 把 `xxx.lrc` 放进这个目录
2. 在 `src/lib/music.ts` 的歌单里给那首曲子加一行 `lyrics`：

   ```ts
   {
     id: "my-song",
     title: "歌名",
     artist: "歌手",
     src: withBasePath(musicUrl("my-song.mp3")),
     lyrics: lyricSrc("xxx.lrc"),   // ← 这一行
   }
   ```

**不填 `lyrics` 也完全没问题** —— 歌词窗会显示「这首歌还没有歌词」，不会报错。

## LRC 怎么写

```text
[ti:曲名]
[ar:歌手]
[offset:0]              整体偏移，单位毫秒，正数表示歌词延后

[00:00.00]第一句
[00:12.34]第二句
[01:02:00]一分零二秒
```

解析器（`src/lib/lyrics.ts`）认这几种时间写法：

| 写法 | 含义 |
| --- | --- |
| `[mm:ss.xx]` | 百分秒（最常见） |
| `[mm:ss.xxx]` | 千分秒 |
| `[mm:ss:ff]` | 帧（百帧制） |
| `[00:10.00][01:20.00]副歌` | 一行多个时间标签（重复段/合唱） |

**没有时间轴的纯文本歌词**不会被丢 —— 会整段显示出来（不滚动、不高亮）。
`npm run lyrics` 遇到 `.txt` 就是按这个处理的。

## 注意

- 文件要存成 **UTF-8**。带 BOM 也能读（解析器会先去掉），但别存 GBK。
- **歌词是受版权保护的作品。** 博客是公开仓库，往这里提交歌词等于**公开分发**。
  只放你有权利放的内容：自己写的、已授权的，或公有领域的。
  脚本**不会**去任何网站抓取歌词 —— 歌词文本需要你自己提供。
